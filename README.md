# Cabinet Karina - Dental Practice Management System

A Windows-based dental practice management application built with PHP, SQLite, HTML, CSS and JavaScript.

## Overview

Cabinet Karina is designed to support the daily administrative and clinical workflows of a dental practice through a centralized local application.

## Main Features

- Patient management
- Appointment scheduling
- Consultation management
- Treatment tracking
- Dental procedures management
- Invoice management and printing
- Prescription management and printing
- Expense tracking
- Inventory and stock management
- User management and access roles
- Dashboard and activity overview
- Excel data export

## Technology Stack

| Technology | Purpose |
|---|---|
| PHP | Backend application |
| SQLite | Local database |
| HTML | Application structure |
| CSS | User interface |
| JavaScript | Frontend interactions |
| Windows Batch / VBScript | Local Windows deployment |

## Security and Privacy

This repository excludes the local SQLite database, patient uploads, local PHP runtime, backups and local secrets.

Never publish real patient records, medical documents, credentials or confidential information.

## Deployment

The project includes Windows scripts for local installation, startup, diagnostics and server shutdown.

Refer to `LISEZ-MOI-WINDOWS.txt` for the Windows installation instructions.
